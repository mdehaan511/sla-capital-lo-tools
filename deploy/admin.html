User management

Invite users, change roles, or revoke access in the Netlify dashboard.

Open Netlify Identity  ↗

To invite a new user: Click the button above, then Invite users in the Netlify Identity page. They'll receive an email to set their own password.

To change a role: In the Netlify Identity page, click a user, then edit their app_metadata to set {"roles": ["admin"]} or {"roles": ["super_admin"]} or {"roles": ["user"]}. Changes take effect the next time the user logs in.

To remove a user: Click the user in the Netlify Identity page and choose Delete. Access is revoked immediately.

How roles work: user can access all loan tools. admin can also see this Admin page. super_admin can additionally manage site settings (banner, Slack webhook, submission email).
