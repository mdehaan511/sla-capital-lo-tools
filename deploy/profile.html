When a loan reaches Approved with the borrower application complete, an entity, each guarantor, and the loan itself are pushed to Baseline (auto-fire ships in Phase 3 — for now the LO clicks "Send to Baseline" on Loan Details). Configure these env vars in Netlify:
  • BASELINE_API_KEY — required.
  • BASELINE_DRY_RUN — defaults to true. Set to the literal string false to enable real Baseline calls. Anything else (typos, "FALSE", unset) stays in dry-run as a fail-safe.
  • BASELINE_ENABLED — optional kill switch. Set to 0 to disable all calls without unsetting the key.
  • BASELINE_BASE_URL — defaults to https://production.baselinesoftware.com/production/api. Override only if Baseline gave you a different tenant URL.
On sync failure (live mode only) a Slack message is sent to the configured webhook. Field mapping is currently minimal (core fields only) — Phase 2.5 expands it once we have a real Baseline GET /borrower + GET /loan response to map custom fields against.
